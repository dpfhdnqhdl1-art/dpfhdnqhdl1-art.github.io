일상 업무에 맞춘 기능

웹·Android는 계정 공간을 공유하며,
Windows 앱은 로컬 문서 생성도 지원합니다.
제공 기능은 배포판·연결 설정·권한에 따라 달라집니다.

01

개인·팀 일정 관리

연결한 Google 캘린더의 일정을 확인하고, 쓰기 권한이 있는 일정은 추가·수정·삭제합니다. 팀 캘린더와 개인 캘린더의 접근 권한을 구분하며, 개인 캘린더가 팀에 자동 공유되지는 않습니다. 공휴일 연결은 읽기 전용입니다.

02

공유 작업일지

계정 공간의 작업일지는 클라우드(Firestore)에 저장합니다. 배정된 팀에서 기록 작성·수정·검색, 삭제 항목 복원, Excel 내보내기를 지원합니다. 이전이 완료된 일지는 Firestore가 기준이며, 옛 Google 시트에 이중 저장하지 않습니다.

03

Windows 안전문서 생성

PC 앱에서 PM·휴가·한국 공휴일 일정과 문서 양식으로 TBM, 주간 안전회의, 안전점검 문서를 만듭니다. Word·PDF는 지정한 PC 폴더에 저장합니다. 웹·Android에서 PC의 Word 엔진이 자동 실행되지는 않습니다.

04

AI 채팅과 자료 분석

질문과 선택한 이미지·문서를 보내고, 접근 권한이 있는 업무 자료를 참고해 답변을 받습니다. 계정 공간의 AI는 서버의 OpenAI 연결과 관리자 허용 모델·사용 한도를 적용합니다. 로컬 PC의 API 연결 설정은 별도로 관리합니다.

05

Maximo 이력 조회

연결이 설정된 환경에서 WO·SR과 작업 내용·원인·조치, Materials·Labor를 읽기 전용으로 확인합니다. 조회 날짜 기준과 자재 출고·반납을 구분합니다. 서버 접근 권한과 필요한 네트워크 연결이 있어야 하며, 지원 범위는 플랫폼별로 다릅니다.

06

기록 보관과 백업

작업일지의 미저장 초안과 삭제 기록을 복구할 수 있습니다. 관리자가 별도 동의로 Google Drive 백업을 연결하면 작업일지 복구 자료와 월별 Excel을 보관합니다. 백업 보관 개수와 실행 일정은 설정에 따릅니다.

계정으로 연결하고,
권한 안에서 사용합니다.

팀 업무 자료는 배정된 공간과 역할에 따라 접근합니다. 개인 Google 연결과 팀 공용 연결을 구분하고, 필요한 기능을 선택해 사용합니다.

STEP 01

계정과 팀 준비

이메일로 가입하고 인증을 완료합니다. 관리자 승인과 팀 배정 후 팀 기능을 사용하며, Google 연동이 필요한 기능은 별도 연결·동의를 진행합니다.

STEP 02

필요한 자료 선택

일정·일지를 직접 확인하거나 AI에 질문합니다. AI 요청에 포함한 대화·첨부·관련 조회 자료는 설정된 AI 서비스로 전달되므로 필요한 자료만 선택해 주세요.

STEP 03

결과 확인과 저장

변경할 일정과 일지, 생성할 문서를 확인합니다. 팀 일지는 클라우드에, Google 일정은 Google에, PC 생성 문서는 지정한 로컬 폴더에 저장합니다.

이용 환경을 확인해 주세요. 계정 공간의 AI 비용과 한도는 관리자가 운영하며, PC에서 개인 API 키를 설정하는 경우 해당 계정의 이용 조건·요금이 적용됩니다. 일반 PC판은 설정에 따라 Claude·Gemini도 지원합니다. Word·PDF 생성에는 지원되는 Windows·Microsoft Word 환경이 필요합니다.

Windows·Android 배포 파일과 설치 가능 상태는 승인 계정의 계정 공간 또는 배포 담당자의 안내를 확인하세요. Microsoft Store 배포는 준비 중이며, 심사·게시가 완료된 뒤 안내됩니다.

계정 정보, AI 전송, 저장·백업·삭제 방법은 개인정보처리방침에서 확인할 수 있습니다.
