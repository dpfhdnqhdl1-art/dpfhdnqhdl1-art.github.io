워크메이트(WorkMate)는 개인과 소규모 팀의 일정·작업일지·문서·AI 업무 조회를 돕습니다. Microsoft Store 제출 이름은 WorkMate-team입니다. 이 방침은 기능별로 처리하는 정보, 저장 위치, 외부 전송과 이용자의 관리 방법을 설명합니다. 설치만으로 모든 외부 서비스가 연결되지는 않으며, 실제 처리 범위는 사용한 기능·플랫폼·계정 권한에 따라 달라집니다.

주요 안내
계정·팀 설정과 계정 공간의 작업일지는 운영자의 Firebase·Google Cloud 환경에서 처리합니다. 개인 캘린더는 팀에 자동 공유되지 않습니다. AI에 요청하면 대화·선택한 첨부·해당 요청의 참고 자료가 AI 제공자에게 전달됩니다. PC 자료, 클라우드 기록, 백업과 이미 외부에 전송한 자료는 각각 관리해야 합니다.

1. 처리하는 정보와 이용 목적

구분정보와 이용 목적
계정·인증이메일, 계정 식별자, 이메일 인증·승인 상태, 표시 이름, 역할과 팀 배정, 인증 세션 정보를 처리합니다. 가입·로그인·접근 제어·계정 지원에 이용합니다. 이메일·비밀번호 인증은 Firebase Authentication이 처리하며, 비밀번호 원문을 WorkMate 업무 API나 작업일지에 저장하지 않습니다.
설정·운영 기록계정·팀 연결 설정, 답변 선호, 허용 모델과 사용 한도, 요청 식별자·처리 상태, 토큰·비용·사용량, 권한 변경 등 감사 기록을 처리합니다. 설정 유지, 중복 실행 방지, 오류 확인과 이용 한도 관리에 이용합니다.

작업일지·백업일자, 작성자 표시 이름·식별자, 위치, 작업 내용·결과·비고, 수정 정보, 삭제 기록·복구 자료를 처리합니다. 팀 기록 공유·검색·편집·복원·Excel 출력에 사용하며, 연결된 옛 Google 시트의 이전 자료와 선택적으로 생성한 Drive 백업도 포함될 수 있습니다.
AI 대화·첨부질문, 필요한 대화 문맥, 답변 선호, 선택한 파일이나 추출 내용, 해당 요청의 일정·일지·Maximo 참고 자료, AI 응답을 처리합니다. 답변·분석과 요청 결과 확인에 사용합니다. AI 응답에 업무 자료의 일부가 포함될 수 있습니다.
Maximo권한이 허용된 WO·SR, 작업 내용·원인·조치, Materials·Labor, 관련 기록·작업로그·첨부 등 지원되는 항목을 읽습니다. 품번·수량·금액·작업자 코드·시간 등이 포함될 수 있습니다. 검색·상세 조회·요약·내보내기에 사용하며 Maximo에는 쓰지 않습니다.
PC 문서·설정문서 양식·서명 이미지, 저장 경로, API 연결 설정, 생성한 Word·PDF·Excel, 대화·초안·복구 사본을 처리합니다. 로컬 업무 기능을 위한 자료이며, 사용자가 AI 첨부 등으로 선택하면 해당 전송 범위에 포함될 수 있습니다. API 키·인증 토큰을 업무 참고 자료로 AI에 보내도록 구성하지 않습니다.
지원·접속 정보문의 이메일·내용을 답변과 문제 해결에 사용합니다. 호스팅·인증 제공자는 서비스 제공과 보안을 위해 IP 주소, 브라우저·기기 정보, 접속·오류 기록을 처리할 수 있습니다.

2. 개인 자료, 팀 공유와 운영자 접근

계정 공간의 업무 기능은 이메일 인증과 관리자 승인을 거친 계정에 제공하며, 팀 자료는 배정된 팀과 역할에 따라 접근합니다. 팀 기록에는 작성자 정보가 포함될 수 있고, 권한이 있는 팀원이 이를 확인할 수 있습니다. 관리자는 역할에 따라 회원·팀 배정·연결·허용 모델·사용 한도 등을 관리합니다.

개인 Google 캘린더는 팀에 자동 공유되지 않습니다. 팀 공용 연결은 해당 자원의 소유자·관리자가 설정한 Google 연결과 WorkMate의 팀 권한을 함께 확인합니다. PC의 로컬 Google·API 연결은 계정 공간과 별도이며, 앱 설치나 공용 AI 이용만으로 타인의 개인 자료에 접근할 수는 없습니다.

운영자는 클라우드에 저장된 정보에 서비스 운영·지원·보안·삭제 요청 처리에 필요한 범위에서 접근할 수 있습니다. 일반 팀 관리자에게 전체 개인 대화나 개인 캘린더를 열람하는 권한을 제공하는 것은 아닙니다. 로컬 PC 파일과 별도 Google 자료는 운영자가 이를 전달받거나 별도 접근 권한을 얻은 경우에만 접근할 수 있습니다.

3. Google 연결과 요청 권한

Google 동의 화면에서 선택한 계정과 범위를 기준으로 동작합니다. 기능과 연결 방식에 따라 다음 권한을 요청합니다.

  • calendar.readonly: 캘린더·일정 확인, 검색, 문서 생성에 필요한 일정 읽기.
  • calendar.events: 쓰기 권한이 있는 캘린더에서 사용자가 확인한 일정 추가·수정·삭제. 공휴일 연결은 읽기 전용으로 취급합니다.
  • spreadsheets: Google 시트 방식의 기존 일지 조회·작성·이전 및 관련 기능. Firestore로 이전된 일지는 Firestore가 기준이며 옛 시트에 자동 이중 저장하지 않습니다.
  • drive.file: 관리자가 별도로 연결·동의한 작업일지 백업 기능. 앱이 생성하거나 접근 권한을 받은 파일 범위에서 백업 생성·조회·복원과 보관 설정에 따른 정리를 수행합니다. Drive 전체 파일 접근 권한을 요구하는 것은 아닙니다.

캘린더·시트 권한은 Google 동의 화면상 여러 자원에 대한 접근 범위를 포함할 수 있습니다. WorkMate는 설정된 대상과 현재 요청을 검증해 사용합니다. Google에 보관된 자료의 공유 범위는 해당 Google 자원의 공유 설정에도 영향을 받습니다.

4. 외부 서비스로 전달되는 정보

  • Google Firebase·Google Cloud: 계정 인증, 업무 API, 계정·팀 설정, 작업일지, AI 요청 처리·결과·사용량과 운영 기록을 처리·저장합니다. 계정 공간의 AI 요청은 운영자 서버를 거쳐 전달됩니다.
  • Google Calendar·Sheets·Drive: 선택한 기능의 조회·변경 요청과 필요한 일정·일지·백업 데이터를 전달합니다. Drive 백업은 연결한 소유자의 Google Drive에 저장합니다.
  • OpenAI: 계정 공간과 팀 PC판에서 AI 요청에 포함한 질문·대화 문맥·답변 선호·첨부·참고 자료를 전달합니다. 계정 공간에서는 사용자가 선택한 참고 자료를 서버가 권한 확인 후 조회합니다. PC에서는 해당 AI 요청에 따라 도구가 조회한 관련 자료가 포함될 수 있습니다.
  • 그 밖의 PC AI 제공자: 일반 PC판에서 사용자가 선택·설정한 경우 Anthropic(Claude) 또는 Google(Gemini)에 해당 요청 내용을 전달합니다. 팀판의 허용 모델 제한은 별도로 적용됩니다.
  • Maximo: 연결된 서버로 검색 조건과 인증 정보를 보내 읽기 조회를 수행합니다. AI 분석을 요청하면 관련 결과가 AI 제공자에게도 전달될 수 있습니다.
  • 지원 이메일: 문의를 보낼 때 이메일 제공자를 통해 발신 주소·문의 내용·첨부가 전달됩니다. 비밀번호·API 키·인증 토큰은 문의에 포함하지 마세요.

달력·작업일지·Maximo 화면의 일반 조회만으로 그 내용을 AI에 보내지는 않습니다. AI 분석·채팅·연결 검사에는 AI 요청이 발생하며, 후속 질문에는 이전 대화의 관련 내용이 다시 포함될 수 있습니다.

운영자는 Google 사용자 데이터를 판매하거나 광고 타기팅에 이용하지 않으며, 범용 AI 모델의 학습·개선을 목적으로 별도 수집하지 않습니다. Google 데이터는 요청한 사용자용 기능의 제공 범위에서 처리합니다.

외부 제공자는 해외에서도 정보를 처리할 수 있습니다. 처리 지역·보관 기간·API 데이터 이용 조건은 연결한 서비스와 계정의 계약·설정에 따릅니다. 계정 공간의 OpenAI 응답 저장 옵션은 끄고 요청하지만, 이것이 WorkMate 서버의 응답 기록이나 제공자의 모든 보안·운영 보관까지 없앤다는 뜻은 아닙니다. 모든 제공자에 대해 무보관이나 학습 제외를 일괄 보장하지 않습니다.

제공자 안내: Firebase 개인정보·보안 · Google 개인정보처리방침 · OpenAI 비즈니스 데이터 · Anthropic 개인정보 안내 · Google API 사용자 데이터 정책

5. 저장 위치, 보호와 보관 기간

  • 인증·클라우드: 인증 정보는 Firebase Authentication에, 계정·팀 설정과 작업일지·복구 자료·감사·사용량 기록은 Firestore 등 운영 환경에 저장합니다. 중복 AI 호출을 방지하기 위한 요청 기록에는 AI 응답과 모델·사용량 등 결과가 포함됩니다. 현재 이들 업무 기록과 AI 결과에 일괄 자동 삭제 기한을 설정하지 않았으며, 필요한 삭제는 아래 문의 절차로 요청할 수 있습니다.
  • 서버 연결 정보: 서버의 API 비밀값은 비밀정보 관리 기능을 사용하고, Google 연결 토큰은 서버에서 암호화해 보관합니다. 업무 본문 전체가 연결 토큰과 동일한 방식으로 별도 암호화되는 것은 아닙니다.
  • 웹·Android 기기: 로그인 유지 정보, 선택한 공간·캘린더 등 화면 설정과 미저장 일지 초안을 브라우저 또는 앱의 로컬 저장소에 보관할 수 있습니다. 현재 채팅 화면의 대화·선택 첨부는 주로 실행 중 메모리에서 처리하지만, 서버에 남은 AI 응답 기록은 별개입니다. 로그아웃·새 대화만으로 기기의 모든 초안·다운로드가 지워지지는 않습니다.
  • Windows PC: 로컬 설정·OAuth 토큰·대화·일부 조회 결과·사용량·초안·복구 사본은 사용자 프로필에 저장할 수 있습니다. 일반 설치본은 보통 %LOCALAPPDATA%\WorkMate를 사용하며 Store판·실행 방식에 따라 별도 위치를 사용합니다. 저장한 AI·Maximo API 키는 Windows 사용자 보호 기능(DPAPI)을 사용합니다. OAuth 토큰·대화·초안 전체에 같은 보호가 적용되는 것은 아닙니다. 일괄 자동 만료는 설정하지 않았습니다.
  • 첨부·출력 파일: 선택한 원본은 원래 위치에 남으며 처리 중 임시 사본을 사용할 수 있습니다. 대화·응답에는 첨부 이름·추출 내용·분석 결과가 남을 수 있습니다. PC 생성 문서와 사용자가 다운로드한 Word·PDF·Excel은 저장 폴더에서 직접 관리하며 앱 종료·업데이트로 자동 삭제하지 않습니다.
  • 일지 삭제·복원: 화면에서 삭제한 일지는 복원을 위해 삭제 기록으로 남을 수 있습니다. 백업 복원 전 상태와 이전한 시트의 보관 자료도 별도로 남습니다. 화면에서 보이지 않는 상태와 완전 삭제는 다릅니다.
  • Google 자료·Drive 백업: 일정·기존 시트는 Google에 남습니다. 선택적 Drive 백업은 설정된 보관 개수에 따라 새 백업 확인 후 오래된 앱 백업을 휴지통으로 이동합니다. 휴지통 자료, 과거 버전, 내려받은 사본의 보관은 Google 및 사용자의 관리 설정에 따릅니다.
  • 지원·제공자 기록: 문의 메일은 문의 처리와 후속 확인에 필요한 동안 보관하고 삭제 요청을 받습니다. 호스팅·인증·AI 제공자의 보안·접속 기록은 각 제공자의 보관 정책에 따릅니다.
