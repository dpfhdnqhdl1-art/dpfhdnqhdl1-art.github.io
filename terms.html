워크메이트는 개인 및 소규모 팀의 일정 관리, 작업 기록, 문서 작성과 업무 이력 조회를 돕는 Windows 프로그램입니다.

1. 사용 범위

배포받은 프로그램은 본인 또는 소속 팀이 접근 권한을 가진 계정·자료와 연결해 사용합니다. 타인의 계정·인증 파일을 허락 없이 사용하거나, 권한이 없는 업무 자료를 조회·전송해서는 안 됩니다. 프로그램은 Google·OpenAI·Anthropic·IBM의 공식 제품이나 인증을 받은 제품으로 표시되지 않습니다.

2. 계정·키·공유 권한

Google은 사용자별 본인 계정으로 연결합니다. 캘린더와 시트의 공유 권한은 Google에서 별도로 관리합니다. 공용 AI·Maximo 키를 사용하는 경우에도 계정 제공자의 허용 범위와 각 서비스의 이용 조건을 따라야 합니다. 키·토큰·설정 파일은 공개 저장소나 공개 채팅에 게시하지 마세요.

3. 외부 서비스와 비용

AI 요청에는 선택한 서비스의 API 사용료가 발생할 수 있습니다. 해당 계정의 결제·모델 권한·할당량은 서비스 제공자가 관리합니다. Google 및 Maximo 기능은 각 서비스의 가용성, 인증, 공유 권한, 네트워크 조건에 따라 달라집니다. 일부 문서 생성 기능은 Microsoft Word 등 별도 실행 환경이 필요합니다.

4. AI 답변과 업무 결과 확인

AI 답변이나 자동 생성 문서에는 오류·누락이 있을 수 있습니다. 안전문서의 날짜·작업내용·참석자·서명·페이지 구성과 실제 수행 기록은 사용자가 확인한 후 사용합니다. 예정 일정이나 자재 출고 정보만으로 작업 완료가 증명되지는 않습니다. 프로그램에서 제한·부분 조회·검토 필요가 표시되면 원문과 결과를 함께 확인해 주세요.

5. 저장과 수정

시트 기록 저장·수정·삭제 및 일정 변경은 연결한 Google 자료에 영향을 줄 수 있습니다. 중요한 기록과 출력 파일은 사용 목적에 맞게 보관하세요. 복구 기능은 해당 PC에 남아 있는 사본의 범위에서 동작하며 모든 상황의 복구를 보장하지 않습니다.

6. 개인정보 처리

데이터의 접근·AI 전송·로컬 저장·삭제 방법은 개인정보처리방침에 따릅니다. 업무 자료를 AI에 요청하기 전에 본인과 팀이 해당 자료를 전송할 권한을 가지고 있는지 확인합니다.

7. 변경과 문의

개인 운영 프로그램의 기능과 지원 범위는 버전별로 달라질 수 있습니다. 업데이트 파일은 배포 담당자에게 전달받아 수동 적용합니다. 중요한 변경 사항은 배포 안내와 이 사이트를 통해 알립니다.
